EXPERIENCE

Projects and experiences that I created

KORMS RNG

Developed KORMS RNG, an RNG adventure game on Roblox where players spin to get different auras with rare chances like 1/1B and 1/10B. The game also has quests, hidden artifacts, and collectible items that players can find while exploring the map. It includes weather events that give extra luck and help players get rarer auras. This project helped improve my skills in game development, game systems, and creating fun experiences for players.

BRAINROT GLASSBRIDGE

Developed BRAINROT GLASSBRIDGE, a game on Roblox inspired by glass bridge challenge games where players must choose the correct path to survive and reach the finish line. Players receive rewards after completing the game, and the game also includes paid brainrot items that players can buy for extra features and fun effects. It has a leaderboard system for top players, guess-the-door challenges, and group claim rewards for community members. This project helped improve my skills in scripting, reward systems, leaderboards, and multiplayer game design.

GRAPHIC AND VIDEO EDITING
